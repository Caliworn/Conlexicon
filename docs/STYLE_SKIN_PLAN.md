# Style Skin Plan

本文记录 Conlexicon 样式解耦阶段 S0 的边界、皮肤 token 契约和验收基线。S0 只建立可替换皮肤基础，不改变当前经典明暗主题的视觉，也不增加皮肤设置或持久化字段。

## 1. 文件边界

- `theme-tokens.css`：语义颜色、材质角色和少量可换肤几何值。
- `styles.css`：布局、组件、状态和响应式规则；完成 S0 后不得继续包含主题相关颜色或材质字面量。
- 当前不拆分其余组件 CSS。未来皮肤只能覆盖 token，不应向组件 DOM 添加 `glass` 等皮肤类。

## 2. Token 层级

语义颜色以 `--ui-*` 命名，表达画布、文字、边框、强调、警告、危险和焦点等含义。材质角色以 `--material-*` 命名，分别表达 panel、control、inset、floating、mobile-bar、navigation、tooltip 和 overlay 的背景、边框、阴影与滤镜。圆角只保留 control、panel、floating 和 pill 四种角色。

布局间距、虚拟列表尺寸、网格轨道、响应式断点和 z-index 不属于皮肤，不迁入 `theme-tokens.css`。`uiTheme` 仍只表达 light/dark，不在 S0 中引入 skin 设置。

## 3. S0 基线与边界

S0-1 已把原 `:root` 和 `body.dark-theme` 主题值迁入 `theme-tokens.css`，并在 `index.html` 中先于组件样式加载。S0-2 将文字、边框、状态色和焦点环迁入 `--ui-*`。S0-3 将画布、面板、控件、内嵌区、浮层、固定区、导航、tooltip、overlay 和移动端外壳迁入对应 `--material-*`，删除组件级暗色分支及全部迁移别名。

由于自定义属性在声明所在元素上求值，定义于 `:root` 的派生 token 不会因后代覆盖其基础 token 而重新求值。暗色作用域中需要跟随主题重新求值的派生材质必须就地声明，不能依赖根作用域别名间接更新。

改动前后均以浏览器计算样式抽取以下关键角色：

| 角色 | 浅色背景 / 边框 | 暗色背景 / 边框 | 圆角 | 滤镜 |
| --- | --- | --- | --- | --- |
| 画布 | `#f4f6f2` | `#151a1d` | `0` | `none` |
| 导航 | `#22313a` | `#10181c` | `0` | `none` |
| 控件 | `#ffffff` / `#d8e0e8` | `#1f282d` / `#405057` | `8px` | `none` |
| 面板 | `#ffffff` / `#d8e0e8` | `#1f282d` / `#405057` | `8px` | `none` |
| 浮层 | `#ffffff` / `#d8e0e8` | `#1f282d` / `#405057` | `8px` | `none` |

浅色和暗色的 body、navigation、control、panel、floating 与筛选按钮计算样式在 S0-1 前后逐项一致。

## 4. 当前状态

S0 的代码边界已经完成：`styles.css` 只消费皮肤角色，不声明 `--ui-*`、`--material-*` 或 `--radius-*`，也不包含主题色字面量、组件级暗色分支和直接材质模糊/投影。警告标签和警告徽章按现有不同视觉语义保留独立 token，没有借迁移强行统一外观。

`scripts/check-style-contract.js` 持续验证：

1. `theme-tokens.css` 必须先于 `styles.css` 加载。
2. 皮肤 token 必须有定义，且只能在 token 文件中声明。
3. 组件样式不得恢复旧别名、主题分支或主题材质字面量。

拆分前后已用浏览器确认浅色和暗色的画布、导航、控件、面板与浮层关键计算样式一致。迁移后又使用带形态数据的临时词典完成中英文、明暗主题、320/480/768/1024/1440px、筛选浮层、移动抽屉和确认弹窗验收；各宽度均无页面横向溢出，窄屏浮层保持在视口内，控制台无警告或错误。S0 至此完成。

层叠玻璃或其他皮肤应在 S0 完成后，以独立且有作用域的 token 覆盖文件实现；透明度、模糊、降级策略和性能验收不属于 S0。层叠玻璃 LG-1–LG-4C.1 与液态玻璃 LQ-1–LQ-3 均已完成并正式收尾；后者包含独立运行期、token 基线、静态有界 SVG 折射和严格浮层白名单上的合帧动态焦散。两套玻璃皮肤的具体边界分别见 `docs/LAYERED_GLASS_SKIN_SPEC.md` 和 `docs/LIQUID_GLASS_SKIN_SPEC.md`。
