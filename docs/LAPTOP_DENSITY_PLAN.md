# Laptop Density Plan / 笔记本紧凑密度设计草案

状态：部分实装。导航、页头、词条卡片、词条详情和完整编辑的紧凑档已实装（第 3 节，现行设计）；局部编辑、快速录入和其他页面未实施（第 4 节）。设计于 2026-11-18 做过一次独立复评，取舍见第 5 节。全部完成后，第 3 节迁入 [Style Skin Plan](STYLE_SKIN_PLAN.md) 或 [应用外壳规范](APP_SHELL_SPEC.md)，本文删除。验收状态见交接文档“笔记本紧凑密度”。

本文处理缩放后可用高度不足的笔记本屏幕，典型是 1080p 屏开 150% 缩放。做法是收紧外壳和留白，表单控件尺寸不变。本文不改变数据模型、API、保存范围和未保存检查；移动端词条编辑的重设计见交接文档路线图“云同步与移动端”。

## 1. 问题

尺寸是按 100% 缩放下约 1920×1000 的可用空间定的。缩放把可用空间压到 1280×610 左右时，外框和留白的绝对尺寸不变，挤掉了内容；切回 100% 又会把文字和点击目标一起缩小。改动前在 1280×610 实测：11 个导航工具只看得到 6 个；页头占 96px，内容从视口 124px 处开始；单释义词条的完整编辑表单约 2.3 屏。

目标视口（宽×可用高，CSS px，高度为估算值）：

| 典型设备 | 视口 |
| --- | --- |
| 1080p，150% | 1280 × 610 |
| 1366×768，100% | 1366 × 650 |
| 1080p，125% | 1536 × 750 |
| 1440p，150% | 1707 × 840 |
| 1080p，100%（对照，不应变化） | 1920 × 970 |

## 2. 目标

1. 1280×610 下，展开导航的 11 个工具全部可见，导航不滚动。
2. 内容起点尽量靠上，词条页的页头只占一行。
3. 表单控件高度、输入文字字号和 `pointer: coarse` 下的 44px 命中区不变。词条卡片、词条详情和页头的文字可以缩小。
4. 舒适档下所有尺寸与改动前相同。

## 3. 现行设计（已实装）

### 3.1 界面密度与触发

- 全局偏好 `data/index.json` 的 `uiDensity`：`auto`／`compact`／`comfortable`，接口见 [API 契约](API_CONTRACT.md)。在导航底部的“外观”菜单里选择，菜单分“皮肤”和“界面密度”两组。
- `app.js` 的 `resolvedUiDensity()` 把偏好解析成 `compact` 或 `comfortable`，写到 `body[data-density]`。自动档在宽度不小于 800px、高度不超过 920px 时取紧凑（`compactDensityMediaQuery`）；手动选紧凑时，800px 以下的移动布局也套用页头、卡片和详情的紧凑规则。
- 紧凑规则只按 `body[data-density]` 生效。样式里不写按窗口高度的紧凑规则，样式契约检查禁止重新出现。

### 3.2 密度 token

- 外壳和留白的密度 token 声明在 `body` 上；现行取值以 `styles.css` 开头的密度 token 和 “Compact density” 规则为准。
- 皮肤通过 `--skin-nav-width`、`--skin-nav-padding`、`--skin-nav-item-max-height`、`--skin-nav-item-padding-inline`、`--skin-nav-item-gap` 提供舒适值，紧凑档由共享层直接覆盖密度 token。样式契约检查禁止皮肤直接声明密度 token。液态玻璃的展开宽度 `--liquid-glass-navigation-expanded-width` 读取 `--nav-width`。

### 3.3 导航

- 紧凑档导航宽 220px（英文 272px，因为 “Morphology Functions” 按钮和英文品牌名在 220px 下溢出），导航项左右内边距 10px。
- 导航项高度自适应：`.tool-list` 的行为 `minmax(var(--nav-item-min-height), var(--nav-item-max-height))`，按钮拉伸到行高，列表收缩到导航面板的剩余空间，行在 36px 与最大值之间等分，再不够才滚动。最大值沿用改动前的实际高度：经典与层叠玻璃 54px，液态玻璃 50px，图标栏 50px（`--nav-rail-item-max-height`）。按钮上下内边距固定 4px。
- 项间距 `clamp(2px, calc(2.5vh - 13px), 皮肤值)`：约 600px 高时 2px，920px 时到经典的 10px；液态玻璃最多 4px。
- `@media (pointer: coarse)` 在所有尺寸下把最小行高提到 44px，手机抽屉里的 11 项在 812px 高时也能放下。
- 底部按钮在紧凑档合成一行图标按钮，由 `app.js` 的 `navLabelHidden()` 为标签被隐藏的按钮打开 tooltip。图标栏和底部按钮另有 `--nav-rail-section-gap`、`--nav-utility-min-height`。
- 800 和 1280 两个宽度阈值、800–1279px 强制图标栏的规则不变。

### 3.4 页头

词条页的词条数、词根数和语言名放到词典标题右侧同一行；紧凑档页头不设最小高度，标题 1.375rem。词条页以外的页头只缩小标题和间距，眉标仍在标题上方。

### 3.5 词条卡片与列表估算

- 读音和词性与词头同行；内边距 8px 10px，行距 3px，释义 0.875rem，不设最小高度。
- 列表估算卡片高度按密度取 100 或 145px（`ENTRY_CARD_ESTIMATED_HEIGHT`）。偏好改变或自动档跨过阈值时，`syncUiDensity()` 经 `applyUiDensity()` 更新 `body[data-density]`，估算高度变化时清掉已测高度并重排列表。

### 3.6 词条详情

内边距 16px 18px，分区间距最多 12px；词头 `clamp(1.75rem, 5cqi, 2.125rem)`，正文 0.9375rem，释义 1rem，分区标题 0.875rem；形态表单元格内边距 6px 8px、字号 0.875rem、最小列宽 88px。

### 3.7 完整编辑

- 与详情共用紧凑内边距（16px 18px）、页头分隔（下内边距 12px）和分区间距，切换查看与编辑不跳动。输入文字字号和单行控件高度不缩，只收间距、词形字号和多行框的默认高度。
- 数值：标签与输入框间距 4px；页头内部间距 10px；词形字号 `clamp(1.5rem, 2.2vw, 1.875rem)`；发音框高 42px；释义、词源说明和形态备注等多行框默认两行（`calc(2lh + 22px)`），词条备注三行；释义之间与形态组之间的间距与 10px 取小，释义内部和形态组内部 8px；形态表格单元格内边距 6px 8px。
- “添加例句”“添加释义备注”按钮保持原尺寸。

### 3.8 皮肤

经典只读共享层。层叠玻璃的导航按钮只改材质，尺寸来自共享层。液态玻璃的导航是固定浮层，工具项尺寸、列表间距和工作区左内边距都读 token。

## 4. 待实施

- **L2 其余部分**：局部编辑（`.inline-partial-edit-form`）和快速录入字段，沿用完整编辑的字段 token，不另写一套。
- **L3 其他页面**：设置、语料库、语言文档、形态模板、IPA、标签管理和分析页已继承外壳 token；各页自身的留白逐页测量，记录问题后再调整。
- **已知遗留**：自动档跨过阈值后，尚未读取的列表窗口仍按旧估算高度占位，读到后由窗口比例校正，导航条在这之前的比例会有偏差；液态玻璃图标栏在 610px 及以下高度仍有 1 项要滚动（浮层四周各有 16px 内嵌距）。

## 5. 设计取舍

- **只按高度触发自动档**：宽度不足已由 800／1280 两个阈值和容器查询处理；按宽度触发会把 1440×900 这类高度够用的屏幕误判为紧凑。阈值从初稿的 760px 上调到 920px，因为 1440p 加 150%（约 1707×840）也有问题，而 1080p 100% 的最大化窗口（约 950px）仍应是舒适档。
- **不调整图标栏阈值**：800–1279px 的图标栏是强制的，把阈值提到 1366px 会让 1080p 加 150% 的用户无法展开导航。所以压缩导航行高，而不是改宽度规则。
- **一个总的界面密度**：用户看过对照后认为不需要按区域分别设置；放在“外观”菜单而不是皮肤菜单里，因为密度不是皮肤的属性。
- **导航项按行分配而不是跳档**：跳档会让窗口刚低于阈值时按钮变扁、下方空出一大块。
- **不做**：用 CSS `zoom` 或 `transform: scale` 整体缩放（文字和控件照样变小，还会让 tooltip、浮层定位和液态玻璃几何出错）；全局缩小表单控件；新增笔记本专用的 DOM 或布局分支。
- **副作用**：开着开发者工具或窗口不高时也会进入紧凑档，这时正好需要紧凑；拖动窗口跨过阈值时布局跳一次，属于正常的响应式行为。

## 6. 验收

- 视口：1280×610、1366×650、1536×750、1707×840、1920×970（与改动前对比应无变化），以及 800×600（紧凑档与图标栏同时生效）。`AGENTS.md` 的 UI 验收清单已加入宽而矮的视口。
- 外观：三套皮肤，明暗两种主题，中英文界面；长词典名、长工具名、长标签、长高级筛选名。
- 交互：键盘 Tab 顺序与焦点环；底部图标按钮的 tooltip 与可访问名称；弹窗和 tooltip 的层级；`pointer: coarse` 下导航项保持 44px。
- 样式契约检查覆盖：皮肤不直接声明密度 token；样式中没有按窗口高度的紧凑规则。
