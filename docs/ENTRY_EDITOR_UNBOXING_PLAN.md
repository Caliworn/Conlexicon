# Entry Editor Unboxing Plan / 词条编辑去框化设计草案

状态：U1–U3 已实装，结构已写入 [Style Skin Plan](STYLE_SKIN_PLAN.md)“词条编辑表单结构”。本文只剩 U4：字段材质 token 与形态覆盖表单元格去框，待实施。U4 完成后把有效契约迁入 Style Skin Plan，本文删除。原设计于 2026-10-05 做过一次独立复评，开发者于 2026-10-09 确认各项决定；操作栏吸底（U5）于 2026-10-10 由开发者决定搁置。

本文不改变保存范围、数据模型、未保存检查、API 和字段 `data-field` 契约。

## 1. 目标

- 字段仍可辨认：边界由皮肤以边框、填充或下沿线表达，必须满足非文本对比度要求（第 4 节）。
- 皮肤只换材质：字段外观值作为皮肤 token，由三套皮肤各自完整定义，`styles.css` 只消费。
- 经典皮肤的字段外观保持现状（D1）；差异由两套玻璃皮肤承担。

## 2. 皮肤映射

| 状态 | 经典 | 层叠玻璃 | 液态玻璃 |
| --- | --- | --- | --- |
| 字段默认 | 1px 边框 + 面板底（等同现状） | 无四边边框的较实填充 + 1px 下沿线（D6） | 浅填充（复用现有 `--material-entry-detail-section-background` 字段材质）+ 弱边框 |
| 字段悬浮 | 边框加深 | 填充变亮、下沿线加深 | 填充略加深 |
| 字段聚焦 | `--ui-field-focus` 边框 + `--ui-field-focus-ring`（见 Style Skin Plan“焦点”） | 同左 | 同左（液态玻璃为边缘提亮） |

层叠玻璃当前字段使用实色填充与四边描边。 [现行皮肤规范](LAYERED_GLASS_SKIN_SPEC.md)

## 3. Token 接口

沿用分区分隔接口的例外原则：这些值决定皮肤外观，由三套皮肤在明暗作用域分别完整定义。

| Token | 用途 |
| --- | --- |
| `--material-entry-editor-field-{surface,outline,edge}` | 编辑表单字段默认材质 |
| `--material-entry-editor-field-hover-{surface,outline,edge}` | 字段悬浮 |

- 字段 token 在 `:is(#entryForm, .inline-partial-edit-form)` 作用域内映射为 `--material-control-background/border/shadow`，继续走通用控件规则；聚焦沿用共享焦点 token，不新增焦点或禁用 token。
- 液态玻璃现在在全局把文字输入映射到 `--material-entry-detail-section-background/-border`；编辑表单字段 token 引用同一对值，不改写全局映射，也不改写这两个 token。
- 样式契约检查扩展为：这组 token 在三套皮肤的明暗作用域都已定义，共享规则只消费 token。
- 快速录入浮层的字段行目前是无框行，U4 落地后需统一到同一组 token。

## 4. 可访问性与降级

- **字段边界对比度**：字段的可辨识边界（边框、下沿线，或填充与相邻背景之间）对相邻颜色至少 3:1（WCAG 1.4.11）。层叠玻璃的下沿线和液态玻璃的弱边框需要实测；不达标时加深线色，层叠玻璃不达标则退回四边弱边框（D6），不取消边界。
- **减少透明度／不支持 blur**：两套玻璃皮肤的字段退为实色填充 + 1px 边框，与现有分区降级路径一致。
- **强制高对比**：所有字段恢复 `CanvasText` 边框。

## 5. 形态覆盖表单元格去框（实验，D9 待定）

单元格内的覆盖输入去掉独立边框，由表格单元格线界定，聚焦时显示焦点环。风险是密集表格里只靠单元格线，占位文字（自动生成的默认形态）与已填值可能难以区分。作为实验实施，验收不过就保留单元格输入边框。

## 6. 设计取舍

- **不把字段也去框**：初稿考虑过液态玻璃字段只留下划线，但这损害可辨识性，下划线在玻璃底上也很难稳定达到 3:1。
- **用专用 token 而不是直接覆盖 `--material-control-*`**：覆盖值属于皮肤，按文件边界只能写在皮肤文件里，结果仍是每套皮肤各声明一组值；专用命名能让样式契约逐项检查。数量压到第 3 节的最小集合。

## 7. 验收

- 行为：新建、完整编辑、五类局部编辑的保存、取消和未保存检查不变；`node scripts/check-all.js` 通过。
- 视觉：三套皮肤 × 浅色／深色；长词形、长标签、多释义与多形态组；320／480／768／1024／1440px 和紧凑密度；减少透明度、无 blur、强制高对比；记录字段边界对比度的实测值。
- 形态覆盖表：密集表格中焦点环与占位文字的可读性。
